# СчитайКа 0.3.2

Релиз с доработками после 0.3.1: упрощён вход, добавлено управление неиспользуемыми банками и обновлена документация/статус приёмки NAS.

## Изменения

- **Регистрация отключена:** публичное самостоятельное создание аккаунтов убрано (эндпоинт и UI регистрации удалены). Вход сохранён для существующих учётных записей (и демо-аккаунта, если он включён).
- **Банки — работа с неиспользуемыми:** в списке банков отображается признак использования (`inUse`), добавлен фильтр «Скрыть неиспользуемые» и массовое удаление неиспользуемых своих банков (`DELETE /api/banks/unused`). Системные банки и используемые банки не удаляются.
- **Документация и статус:** в `PLAN.md` и `docs/*` зафиксирована приёмка zip-дистрибутива на реальном NAS (17.11.2026), обновлены описание API/возможностей и карта проекта.

## Проверка

- `dotnet build SchitayKa.sln -c Release` — успешно.
- `dotnet test` — **77/77** пройдено.

- `schitayka-0.3.2-docker.zip` — дистрибутив для Container Manager / NAS.
- `schitayka-0.3.2-app.zip` — собранное приложение для автообновления.
