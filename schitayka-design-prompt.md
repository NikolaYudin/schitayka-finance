# Промт для AI-ассистента: Дизайн SaaS в стиле macOS для "СчитайКа"

**Роль:** Ты — экспертный UI/UX дизайнер и фронтенд-разработчик, специализирующийся на создании премиальных SaaS-интерфейсов в стиле современной экосистемы Apple (macOS Sonoma/Sequoia).

**Задача:** Разработать современный, чистый и интуитивно понятный интерфейс для веб-приложения учета личных финансов «СчитайКа» (SchitayKa).

---

## 📌 Контекст проекта
«СчитайКа» — это веб-приложение для управления личными финансами. Основные функции:
- **Учёт операций:** быстрый ввод дохода/расхода, журнал по месяцам с итогами.
- **Категории и лимиты:** месячные лимиты расходов по категориям с прогресс-барами и контролем перерасхода.
- **Финансовые цели:** копилки с целевой суммой и сроком (расчет ежемесячных отчислений).
- **Анализ бюджета:** динамика доходов/расходов за 6 месяцев, структура расходов, норма сбережений.
- **Управление счетами:** дебетовые/кредитные карты, наличные и вклады (карточки в сетке).
- **Персональные рекомендации:** советы на основе данных (превышение лимитов, низкая норма сбережений и т.д.).
- **Темизация:** полная поддержка светлой, тёмной и системной темы.

---

## 🎨 Требования к дизайну (macOS / Modern SaaS Style)
1. **Стекломорфизм (Glassmorphism):** Используй полупрозрачные фоны с `backdrop-blur-md` или `backdrop-blur-xl` для боковой панели, модальных окон, хедера и карточек. Это создаст ощущение глубины и легкости.
2. **Скругления и формы:** Большие радиусы скругления (`rounded-2xl` или `rounded-3xl`) для карточек, кнопок и полей ввода, в духе современных интерфейсов macOS.
3. **Типографика:** Чистый шрифт без засечек (Inter или системный `-apple-system, BlinkMacSystemFont, "Segoe UI"`). Четкая иерархия: крупные, полужирные заголовки для финансовых сумм, приглушенный цвет (`text-muted-foreground`) для второстепенного текста.
4. **Цветовая палитра:**
   - **Фон:** светло-серый/белый (светлая тема) или глубокий темно-серый/черный (тёмная тема).
   - **Акценты:** системные цвета Apple (синий `#007AFF` для основных действий, зеленый `#34C759` для доходов, красный `#FF3B30` для расходов/превышения лимитов, фиолетовый `#AF52DE` для целей).
5. **Тени и глубина:** Мягкие, рассеянные тени (`shadow-sm`, `shadow-md`) для разделения слоев. Тонкие полупрозрачные границы (`border border-white/10` или `border-black/5`) для усиления эффекта стекла.
6. **Иконки:** Минималистичные, единообразные иконки (используй библиотеку `lucide-react`).

---

## 🖥️ Ключевые компоненты и экраны для реализации
1. **Боковая панель (Sidebar):** Компактная, с полупрозрачным фоном. Пункты: Дашборд, Операции, Бюджет и лимиты, Цели, Счета, Настройки. Активный пункт выделен мягкой подложкой с акцентным цветом.
2. **Дашборд (Главная страница):** 
   - Приветствие и сводка общего баланса.
   - Сетка карточек счетов (визуально напоминающие банковские карты Apple Wallet с мягкими градиентами).
   - График структуры расходов (кольцевая или столбчатая диаграмма).
   - Блок "Персональные рекомендации" (в виде аккуратных карточек-уведомлений с иконками).
3. **Виджет лимитов:** Прогресс-бары для категорий (Еда, Транспорт и т.д.) с плавной цветовой индикацией (зеленый → желтый → красный при приближении к лимиту).
4. **Кнопка действия (FAB):** Заметная, но элегантная кнопка "Добавить операцию" (+) в хедере или в виде плавающей кнопки с плавной анимацией при наведении.

---

## ⚙️ Предпочтительный технический стек
- **Фреймворк:** React (Next.js или Vite)
- **Стилизация:** Tailwind CSS
- **Компоненты:** shadcn/ui (для базовых элементов: кнопки, инпуты, диалоги, прогресс-бары, карточки)
- **Анимации:** Framer Motion (для плавных, "яблочных" анимаций появления, hover-эффектов и переходов)
- **Графики:** Recharts
- **Иконки:** lucide-react

## 📝 Инструкция по генерации
1. Начни с создания общей разметки (Layout) с боковой панелью и основной областью контента.
2. Реализуй компонент "Карточка счета" с эффектом стекломорфизма и мягким градиентом.
3. Создай секцию дашборда с графиком, виджетами лимитов и блоком рекомендаций.
4. Убедись, что интерфейс выглядит премиально, "воздушно" (используй достаточные отступы `p-6` или `p-8`) и полностью адаптивен (mobile-friendly).
5. Добавь переключатель светлой/тёмной темы в хедер.
6. Сгенерируй полный, готовый к запуску код для этого интерфейса.
