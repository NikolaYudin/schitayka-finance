# СчитайКа — Android-приложение (.NET MAUI Blazor Hybrid)

Мобильный клиент для сервера СчитайКа. Это настоящее Android-приложение (APK) с
интерфейсом на Razor/HTML/CSS внутри BlazorWebView и доступом к нативным сервисам
устройства (защищённое хранилище JWT). Бэкенд не изменяется — приложение работает
с тем же REST API и JWT, что и веб-версия.

## Что умеет

- Первый запуск: если администратор ещё не создан — форма «Создать администратора»
  (`/api/setup/admin`), иначе обычный вход по email/паролю.
- Главная: общий баланс, доходы/расходы месяца, список счетов, последние операции,
  рекомендации.
- Операции: список по месяцам с переключением.
- Настройки: изменение адреса сервера (без пересборки APK), смена пароля, выход.
- JWT хранится в Android Keystore через `SecureStorage` — сессия переживает перезапуск.

## Адрес сервера

По умолчанию: `http://10.0.2.2:5023` — эмулятор Android обращается к хосту по этому адресу.

На реальном телефоне укажите IP NAS в локальной сети, например `http://192.168.1.10:5023`.
Адрес меняется в экране входа («Адрес сервера») или в «Настройках».

Для HTTP-сервера в манифесте включён `android:usesCleartextTraffic="true"`.
Если поднимете HTTPS — можно убрать.

## Сборка APK

Окружение разработчика:

- .NET SDK 10 + workload `maui-android` (`dotnet workload install maui-android`);
- JDK 17+ и Android SDK (устанавливаются вместе с Visual Studio / Android Studio).

Переменные окружения (пример для Windows PowerShell):

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\openjdk\jdk-21.0.8'
$env:ANDROID_HOME = 'C:\Program Files (x86)\Android\android-sdk'
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
```

Команда сборки:

```powershell
dotnet publish mobile/SchitayKa.Mobile/SchitayKa.Mobile.csproj `
  -c Release -f net10.0-android -o mobile/artifacts
```

Готовый APK: `mobile/artifacts/ru.schitayka.app-Signed.apk`.

## Установка

1. Скачайте `schitayka-0.4.0-android.apk` из релиза на GitHub.
2. Перенесите файл на телефон и откройте его.
3. Разрешите установку из «неизвестных источников» для файлового менеджера/браузера.
4. При первом запуске укажите адрес сервера и создайте администратора (если сервер новый).

APK подписан встроенным ключом разработки — этого достаточно для личной установки,
но для Google Play нужен собственный keystore и подпись релизного AAB.

## Ограничения первой версии

- Нет офлайн-режима: данные всегда приходят с сервера.
- Добавление/редактирование операций из приложения пока не реализовано — только просмотр
  и настройки. Это следующий шаг после проверки удобства использования.
- Push-уведомления и нативная камера/QR не подключены; QR-импорт доступен в веб-версии.
